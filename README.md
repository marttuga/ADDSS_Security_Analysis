# ADDSS - Arquitetura, Desenho e Desenvolvimento de Software Seguro

Repository for coursework and practical security analyses developed for the **ADDSS** module within the **SWitCH Cyber** postgraduate program at **ISEP**.

---

## 📌 Repository Overview

This repository aggregates security research, threat modeling, and static code analysis across different course assignments:

- **Milestone 1 (M1) - Vulnerability Survey & Analysis**
  - Vulnerability analysis and exploitation mechanism research across three target CVEs:
    - **CVE-2023-21716**: Microsoft Word RTF Heap Buffer Overflow.
    - **CVE-2025-21298**: Windows Outlook Remote Code Execution / Memory Corruption.
    - **CVE-2022-29864**: OPC UA / Industrial Automation System Vulnerability.

- **Milestone 2 (M2) - Threat Modeling & SAST Audit (`TutorialWS`)**
  - Application security review of the REST API `TutorialWS` (Java / Spring Boot).
  - Threat Modeling using STRIDE & Data Flow Diagrams (DFDs) with OWASP Threat Dragon.
  - Static Application Security Testing (SAST) using SpotBugs.

- **Languages & Frameworks**: Java, Spring Boot, Python, C++
